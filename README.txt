GLOW PATH SUPPORT SITE

Files:
- index.html       -> Support page
- privacy.html     -> Privacy Policy
- style.css        -> Site styling

GitHub Pages (simple setup):
1. Create a NEW PUBLIC GitHub repository, e.g. glowpath-support.
2. Upload these three files to the root of the repository.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose:
   Source: Deploy from a branch
   Branch: main
   Folder: /(root)
5. Save and wait for GitHub Pages to publish.

Your URLs will normally look like:
https://YOUR-GITHUB-USERNAME.github.io/glowpath-support/
https://YOUR-GITHUB-USERNAME.github.io/glowpath-support/privacy.html

In App Store Connect:
Support URL  -> the first URL
Privacy Policy URL -> the privacy.html URL
