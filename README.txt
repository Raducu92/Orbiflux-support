# ORBIFLUX SUPPORT SITE

Files:

- `index.html` -> Support page
- `privacy.html` -> Privacy Policy
- `style.css` -> Site styling

## GitHub Pages setup

1. Create a new public GitHub repository, for example:
   `orbiflux-support`

2. Upload these three files to the root of the repository.

3. Open:
   `Repository Settings > Pages`

4. Under **Build and deployment**, choose:

   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/(root)`

5. Save and wait for GitHub Pages to publish.

Your URLs will normally look like:

`https://YOUR-GITHUB-USERNAME.github.io/orbiflux-support/`

`https://YOUR-GITHUB-USERNAME.github.io/orbiflux-support/privacy.html`

## App Store Connect

Use:

- **Support URL** -> main Orbiflux support page
- **Privacy Policy URL** -> Orbiflux privacy policy page

Example:

`https://YOUR-GITHUB-USERNAME.github.io/orbiflux-support/`

`https://YOUR-GITHUB-USERNAME.github.io/orbiflux-support/privacy.html`

## Google Play Console

Use the same Privacy Policy URL for the Android release where required.

## Important

Review and update the Privacy Policy whenever Orbiflux adds or changes:

- analytics
- sign-in or user accounts
- cloud saves
- advertising networks
- mediation partners
- attribution or tracking SDKs
- crash reporting services
- any other SDK or feature that changes data collection or sharing
